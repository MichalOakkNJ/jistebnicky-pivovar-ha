# Jistebnický minipivovar

Tento repozitář obsahuje pouze instalační popis doplňku pro Home Assistant. Aplikace se stahuje jako předpřipravený obraz z GitHub Container Registry.

## Instalace

V Home Assistantu otevřete **Nastavení → Doplňky → Obchod s doplňky → Repozitáře** a přidejte adresu tohoto repozitáře. Poté nainstalujte **Jistebnický minipivovar**.

Data várek jsou ukládána v úložišti doplňku Home Assistantu a nejsou součástí tohoto veřejného repozitáře.
